RÉSOLVEUR DE FONCTIONS — VERSION PRO

Fonctions :
- Affine
- Linéaire
- Polynôme du second degré
- Puissance
- Exponentielle
- Logarithme

INSTALLATION
1. Installer Python 3.
2. Ouvrir un terminal dans le dossier.
3. Exécuter :
   pip install -r requirements.txt

LANCEMENT
Windows :
   python main.py
ou double-cliquer sur lancer_windows.bat

Linux / macOS :
   python3 main.py
ou :
   ./lancer_linux_mac.sh

FONCTIONNALITÉS
- Interface graphique Tkinter
- Paramètres adaptés au type de fonction
- Analyse mathématique
- Calcul des racines quand cela est possible
- Domaine pour le logarithme
- Variation de certaines fonctions
- Tableau de 11 valeurs
- Courbe intégrée dans l'interface
- Zoom, déplacement et navigation Matplotlib
- Enregistrement de la courbe en PNG/JPG
- Réinitialisation complète

EXEMPLES
Affine :
a=2, b=1 → f(x)=2x+1

Linéaire :
a=3 → f(x)=3x

Polynôme :
a=1, b=0, c=-1 → f(x)=x²-1

Puissance :
a=2, n=3 → f(x)=2x³

Exponentielle :
a=1, b=2 → f(x)=2ˣ

Logarithme :
a=1, b=2 → f(x)=log₂(x)
